PROJECT NAME: M-TAP

PROJECT DESCRIPTION:
A one-tap M-pesa payment system designed to reduce supermarket checkout queues and make payments faster and easier 

Team Members:
	Victor Yaah -  BSCCS/2025/33592
	Annah Waitita -  BSCCS/2025/67059

	Eric Muli - BSCCS/2024/57153
	
Three User Stories:
	1.As a customer, I want faster payment so that I don't waste time or send money to the wrong recepient.
	2.As a cashier, I want easier payment confirmation so that I can quickly serve the customer reducing the queue.
	3.As a manager, I want to view and track all payments, so that I can monitor transactions and manage the supermarket's finances.
